#+title: Retired process-control experiment
#+PROPERTY: status retired

The optional Perl guardian experiment was retired when the native guardian moved
from C to Rust. The previous implementation and experiment remain in Git history.
Neither Perl nor project-owned C source is used by the current guardian or its
tests. Rust builds still require the platform linker and system libraries.

* Preserved behavior and coverage
| Experiment behavior | Current coverage |
|---------------------+------------------|
| Prepare identity before release; private command output | test/gate/gate_guardian_test.exs READY row |
| Parent loss before GO prevents execution | Same suite, unreleased-command parent-loss row |
| Real exit code; signal is not successful exit | Same suite, completion and signalled-worker rows |
| Leader exit does not prove group completion | Same suite, whole-owned-group completion row |
| Kernel-derived identity, read-only process facts | test/gate/gate_guardian_unit2_test.exs probe rows |
| TERM-resistant worker requires bounded escalation | test/gate/gate_guardian_test.exs TERM row, now a shell fixture |
| Failed or malformed process enumeration is unknown | Same suite M5; Rust fact-reader unit tests |

The old six mock-ps parsing cases tested a mechanism the product no longer uses.
The guardian reads OS facts directly; malformed input and I/O failures are covered
in native/gate_guardian/src/facts.rs. Its Linux parser tests run on macOS too;
that is parser evidence, not evidence of Linux kernel behavior.

The delivered protocol and its limits are in
[[file:../contracts/gate-guardian-protocol.org][the guardian contract]]. In particular,
settlement of an owned process group does not prove that an escaped descendant died.
