* Obligation
An external application (the console) reaches the core ONLY through modules the top boundary exports:
=AiOrchestrator.Commands=, =AiOrchestrator.Prepare= and =AiOrchestrator.Query=. Reads are projection-derived; the
verified journal prefix is used and =pending_repair= is exposed as data, never executed; nothing is written by a read.
Mutations run through =Prepare= (the CLI's own admission rules, shared) and =Commands.invoke=; the public entry uses the
core's built-in foreground executor (=Run.Executor=) chosen inside core (A1). Browser input never selects identity, roots,
paths, executor, adapter, clock or id seams: the public request is exactly a verb and a run handle (=run_ref=).
The CLI keeps its directory-based path, its error maps, exit codes, projection files and its pane-claim lifetime
(the outcome callback runs inside the claimed operation before release, A2) byte for byte.

* Public API (exact shapes; A3)
- =Prepare.validate(run_ref, server_opts)= :: ={:ok, %{spec_hash, plan_hash}} | {:error, rejection}=
- =Prepare.start/2=, =Prepare.resume/2=, =Prepare.cancel/2= :: ={:ok, %Prepare.Prepared{}} | {:error, rejection}= (opaque struct)
- =Prepare.invoke(actor, prepared, server_opts)= :: ={:ok, %{events: [map()], close: :ok | {:error, map()}}} | {:error, rejection}=
- =Prepare.supported_verbs()= == =["start", "resume", "cancel"]=; =Prepare.verb(term)= :: ={:ok, verb} | {:error, %{clause: "command_verb_unsupported"}}=
- =Query.list_runs(server_opts)= :: ={:ok, %{runs: [%{run_ref, run_id, status, last_seq, error}], skipped_outside_root: n}} | {:error, rejection}=
- =Query.run_summary(run_ref, server_opts)= :: ={:ok, %{run_ref, run_id, status, last_seq, summary, rendered, pending_repair}} | {:error, rejection}=
- =Query.run_context(run_ref, server_opts)= :: ={:ok, %{run_ref, rendered, pending_repair}} | {:error, rejection}=
- =Query.host_view(run_ref, server_opts)= :: ={:ok, host_view} | {:error, rejection}= where host_view =
  =%{run_ref, run_id, registered, live, generation, other_registered_directories, mounted_phase, errors}= (A4: the count is
  root-filtered =Host.lookup_run_id= entries excluding this directory; unavailable lookup -> =:unknown=; no pids/paths/handles)
- =Query.resolve(run_ref, server_opts)= :: ={:ok, run_dir} | {:error, %{clause: run_ref_invalid | run_ref_outside_root | runs_root_missing | run_directory_missing | run_directory_invalid}}=
- rejection :: =%{clause: String.t(), detail: map() | nil}=; closed clause set: the resolver clauses above, run_inputs_missing,
  run_inputs_invalid, journal_missing, journal_empty, journal_invalid, pane_claim_refused, pane_release_failed, and every
  existing command/journal clause passed through; =detail= carries the trusted tier's original reason map unchanged.
- server_opts (server-only, never from a request): =root=, =budget_ms= (default 1_000; bounds the host observation legs
  after resolution and the verified read, A4), plus the CLI's seam keys (fs, id, clock, dispatch, gate, pane registry, operator).
- Private tier =Prepare.Trusted= (not exported by the top): directory-based =validate/1=, =start/2=, =resume/2=, =cancel/2=,
  =invoke(actor, prepared, executor, outcome, fsm_opts)= where =outcome= runs while the claim is held (A2).
