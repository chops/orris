#+title: Recovery acquisition: cold evidence, appending authority, truthful cleanup
#+options: toc:nil
#+PROPERTY: status delivered contract

* Implementation status
Delivered. =AiOrchestrator.Run.Recovery= (=lib/ai_orchestrator/run/recovery.ex=) implements =evidence/2=,
=acquire/2= and =release/1= with the refusal domain, cleanup map, residue and call-timeout handling below.
The rows are =test/run/recovery_acquisition_red_test.exs= (controls and witnesses),
=test/run/recovery_acquisition_green_review_test.exs= (RG-1..RG-4),
=recovery_acquisition_green_successor_test.exs= (L-1, L-1b, H-1, T-1..T-3) and
=test/run/recovery_acquisition_timeout_followup_test.exs= (F-1/F-2). Not delivered: automatic
fresh-snapshot decision retaking and full recovery-service wiring (no registry, no owner process, no restart
loop).

* Scope
Cold evidence, appending authority and truthful cleanup reporting ONLY. The wrapper writes no event,
acceptance, reservation or terminal and admits no replacement effect; opening may execute only the Writer's
existing bounded repair. No registry, no new owner process, no hidden retry, no callback in the Writer, no
new dependency, NO new Writer API (RA-M2: the wrapper reports only what the existing returns carry,
structurally; it never parses =detail=). The verified-snapshot primitive is delivered by =Writer.verified/1= /
=append/3=: =docs/contracts/writer-snapshot.org= is the ONLY snapshot contract. Automatic fresh-snapshot
decision retaking and full recovery-service wiring are NOT delivered.

* Module and placement
=AiOrchestrator.Run.Recovery= in the Run boundary (already depends on Journal), a consumer over =Reader.load=,
=Writer.open/verified/close=, =Ownership.status= and =RunLock=. No struct: the success handle is the smallest
explicit map.

* Caller precondition (RA-M6)
=Writer.open= links the Writer to the caller, so a Writer that dies during verification sends the caller a linked
exit that =catch_exit= cannot contain unless the caller traps exits (control C-11: a non-trapping caller goes DOWN
=:killed= and the held lock remains). =acquire/2= and =release/1= therefore REQUIRE a trapping caller:
=Process.info(self(), :trap_exit) == {:trap_exit, true}=, checked FIRST - before any option or handle check and
before any IO - else the closed refusal =%{clause: "recovery_caller_invalid", field: "trap_exit", stage: "caller",
cleanup: none}=. The wrapper never mutates the caller's flag. =evidence/2= has no caller precondition. The executor
Owner already traps; no new owner process or registry. The linked success lifetime is unchanged.

* Public interface
- =evidence(run_dir, opts \\ [])= :: ={:ok, evidence} | {:error, refusal}= - COLD EVIDENCE, never authority.
  =evidence = %{lines, seq, last_line_sha256, envelope_version, version_2_from, receipt, repair}= (the verified
  keys WITHOUT =generation= and =token=). Options: only =fs:= (explicit seam). Proven: zero mutating seam ops, no
  =run.lock.*= created, =Ownership.status= unchanged, works under a live OS holder and a live in-BEAM Writer.
- =acquire(run_dir, opts)= :: ={:ok, handle} | {:error, refusal}= - APPENDING AUTHORITY.
  =handle = %{writer: pid, generation: pos_integer, snapshot: verified_snapshot_with_token, repaired: repair | nil}=.
  =repaired= is the OPEN's executed repair evidence (=opened.repair=); =snapshot.repair= is =verified='s CURRENT
  pending evidence - distinct sources, never copied. Success requires a verified snapshot WITH a token; a pending
  repair or any verification refusal or EXIT after open is a refusal at stage "verify": the wrapper observes the
  allocated Writer (its pid and DOWN), closes it when it is alive, and reports the cleanup the close return proves.
  The Writer is linked to the caller (=Writer.open='s link): caller death takes it down. Success admits ONLY an
  explicit caller =Writer.append(writer, event, fence: handle.snapshot.token)=; the wrapper writes nothing.
  Options: REQUIRED =lock:= a proper keyword list carrying a non-empty binary =supervisor_instance= (typed check
  before any IO) whose keys are EXACTLY within the closed nested set =[supervisor_instance, pid, pid_start,
  owner_status, token]= (RG-M2: any other nested key is =recovery_option_invalid= field "lock" before IO, never
  echoed); =create:= REFUSED; explicit seams =fs:= / =clock:= / =ownership:= and those lock seams pass through
  UNCHANGED and are never defaulted (without seams the lock file's =pid= is =System.pid()=). Unknown or duplicated
  keys, non-keyword lists, improper lists: refused before IO.
- =release(handle)= :: =:ok | {:error, refusal}= - explicit release responsibility (=Writer.close=). The handle
  must be exactly the map above, keys AND values (RG-M3): a pid =writer=, a positive integer =generation=, a map
  =snapshot=, =repaired= a map or nil - else =recovery_option_invalid= field "handle" before any call reaches the
  Writer (a malformed handle never closes or kills anything). The Writer stops on a genuine release; a Writer that
  is already gone is reported, not assumed released.

* Call timeout is not death (RG-M1)
=Writer.verified/1= and =Writer.close/1= are bounded calls (5 s). A call that TIMES OUT (=exit {:timeout, _}=) is
distinguished from the Writer's exit: the Writer is alive and still this attempt's responsibility. The wrapper
then attempts a bounded orderly =Writer.close= and, only if that times out too, terminates this exact owned BEAM
Writer (=Process.exit(writer, :kill)=) and waits for its DOWN. Never an OS signal, never forced lock removal, never
a hidden retry, never a global trap flag, never a new owner process. Reported: =reason "writer_timeout"= (a
closed reason added by this revision) with =cleanup= = what the close return proved (legs) or, after a kill or an
unobserved DOWN, =unknown / :retained / unknown= - the lost reply of a timed-out call is never invented. A genuine
exit keeps =reason "writer_exit"=. The monitor wait is itself bounded (5 s) with an explicit =:unobserved= outcome
that yields =cleanup unknown= rather than success (=release/1= then refuses with =writer_timeout=, never =:ok=).
A verify-stage refusal whose orderly close timed out additionally carries =close: "writer_timeout"=.

* Refusal domain (closed; admits uncertainty - RA-M3 / choice 2)
=refusal = %{clause, stage, cleanup}= with =clause= in "journal_unavailable" | "journal_corrupt" |
"recovery_caller_invalid" | "recovery_option_invalid" | "recovery_release_failed" and =stage= in "caller" |
"options" | "ownership" | "lock" | "start" | "read" | "repair" | "descriptor" | "verify" | "release"; plus =field= (option/handle refusals), =source=
("journal" | "receipt"), =reason= (a closed clause name or the Writer's repair stage), =at_seq= (integer, when the
Reader names one), =release= (the STRUCTURED nested release clause - ONLY from =writer_open_cleanup_failed=),
=legs= (the STRUCTURED leg names from =close_failed=: "descriptor" | "lock"), =close= ("writer_timeout" only: a
verify-stage refusal whose orderly close timed out) and =residue=.
- =journal_unavailable= WITHDRAWS "transient/retryable": it never grants retry, effect admission or automatic
  re-acquisition; attention cases (permissions, missing input, ownership ambiguity, failed cleanup) live here.
- =cleanup= is ALWAYS present and closed:
  =%{lock: :none | :released | :removed_unsynced | :unproven | :unknown, registration: :none | :released | :retained | :unknown, descriptor: :none | :closed | :unproven | :unknown}=
  A RELEASED lock is witnessed by =RunLock.owner= reading =:none= (RunLock's released tombstone stays on disk by
  design); a REMAINING held file is witnessed by its basename still present. =:none= = this attempt acquired nothing of that kind; =:released= / =:closed= = proven by the seam's SUCCESS
  return; =:removed_unsynced= = RunLock proved the file absent but its durability unproven; =:unproven= = the
  seam's failure return says the resource may remain; =:unknown= = no return exists that proves either way (an
  init crash, a Writer that died during verification, a handle whose Writer is already gone). Never =:none= or
  =:released= without the corresponding evidence; never forced removal; never another generation's lock.
- =residue= (optional; RA-M7) = =%{kind: :generation | :candidate | :unknown, generation: pos_integer | nil, ours: true | false | :unknown}=
  - a TOKEN-FREE closed description of a file the seams report as possibly remaining. The source is always a
  STRUCTURED path field of the seam's error (=lock_path=, RunLock's =path= - absolute); its basename is extracted
  (=Path.basename/1=) and matched against the absolute-end grammars =\Arun\.lock\.([1-9][0-9]{0,11})\z= (generation
  file) and =\Arun\.lock\.([1-9][0-9]{0,11})\.[A-Za-z0-9_-]{1,64}\.tmp\z= (candidate: its name CARRIES the token, so
  the name itself is never reported); =generation= is that positive capture; any other basename is =kind :unknown,
  generation nil=. Raw filename or token bytes are never promoted into a refusal. =ours= is =true= only where the seam structurally
  proves it (the Writer's own =writer_open_cleanup_failed.lock_path= / the nested release's own record), =false= where
  the seam proves this attempt did not create the file (=candidate_conflict=, =reclaim_failed=), else =:unknown= -
  in particular the opaque =close_failed= lock leg (control C-7b: a held file whose token was replaced closes
  with only leg + detail and the FOREIGN file remains) reports the handle's generation with =ours :unknown=.
  Where the seam carries no path (=lock_unavailable= rollback "not_ours", control C-8b) NO residue is reported.
- No seam reason bytes, no journal bytes (the Reader's =event_type= echo is dropped), no prompts/commands.

* Choices
1. =candidate_conflict= -> cleanup =:none= for this attempt's resources; the residue names the preexisting candidate
   without claiming it (=ours: false=); the earlier "own-temp withdrawal" text was false and is withdrawn.
2. Init failure and Writer death during verification report =:unknown= where no return proves the state.
3. Repair-stage =reason= is the Writer's structured stage ("truncate" | "receipt").

* History
The interface went through several review revisions (the trapping-caller precondition, token-free
source-true residue, dependency-ordered identity-bound teardown, independent fixture directories, bounded
holder shutdown proof, call timeout distinguished from death, the closed nested lock set, and handle value
checks); the RA-M and RG-M labels in the rows above name those findings, and all corrections are folded
into the text above.
