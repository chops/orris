* Interface
=AiOrchestrator.Run.Recovery.Exhaustion.judge(budget_view, consumed)=

- PURE. No IO, no process creation, no clock, no diagnostics, no event building, no state. Same inputs, same
  output. It authenticates no run, no Writer, no journal, and grants NO capability: the result is a calculation
  over supplied facts, never permission to append or to replace effects.
- =budget_view= is exactly the =RunSpec.budgets/1= result shape, but the tag is NOT validation evidence: the
  function is directly callable, so a ={:typed, map}= payload is re-judged by =Spec.Budgets.validate/1=.
- =consumed= is a caller-supplied non-negative INTEGER (the count of =run_recovery_reserved= already in the
  verified prefix). The judge does not know where it came from. No snapshot, handle or cause argument.
- Public surface of the module is exactly =judge/2=.

** Returns (closed)
| result | when |
|--------+------|
| ={:reserve, consumed + 1}= | typed, =restart_attempts= configured, =limit > consumed= |
| ={:exhausted, %{limit: limit, consumed: consumed}}= | typed, configured, =consumed >= limit= (including 0/0 and =consumed > limit=) |
| ={:error, %{clause: "restart_budget_unset"}}= | typed and VALID, =restart_attempts= absent (R-e) |
| ={:error, %{clause: "restart_budget_untyped"}}= | proper ={:legacy, map}= with =is_map(map)=, whatever it contains (R-e) |
| ={:error, %{clause: "restart_budget_invalid"}}= | any other budget view: ={:typed, x}= failing =Budgets.validate= (nil, struct, unknown key, bool, integral float, below minimum, null, any known-field bound), ={:legacy, non_map}=, ={:error, _}=, bare map, nil, atom, wrong-arity tuple, anything else |
| ={:error, %{clause: "recovery_count_invalid"}}= | =consumed= not a non-negative integer (negative, float, boolean, nil, list, map, struct, binary) |
Refusal maps carry the =clause= key ONLY. Nothing from the input is copied into any REFUSAL (no field names, no
values, no unknown keys); the =exhausted= return intentionally carries the =limit= and =consumed= integers. Integers are unbounded: no finite upper bound is imposed absent a declared one, and
large integers are compared exactly (no coercion, no overflow, no default).

** Precedence (deterministic, pinned)
1. Classify and validate the budget view. Outcomes: =typed(map)= (validated), =untyped=, =invalid=. =untyped= and
   =invalid= refuse HERE, before =consumed= is inspected.
2. Validate =consumed=. Invalid refuses =recovery_count_invalid=.
3. Decide: absent =restart_attempts= -> =restart_budget_unset=; else reserve/exhausted.
Consequences pinned by tests: a VALID typed view missing the key with an invalid count -> =recovery_count_invalid=
(count precedes unset); an invalid view with an invalid count -> =restart_budget_invalid=; a legacy view with an
invalid count -> =restart_budget_untyped=. =max_attempts_default= is never a fallback for =restart_attempts=.

* R-e (eligibility rule)
Omission of =restart_attempts= is neither 0 nor infinity: automatic reservation is NOT eligible and the judge
refuses =restart_budget_unset= without any implicit terminal, attention or resume action. A legacy (v1) budget
map refuses =restart_budget_untyped= even when it carries the same numeric field; v1 is never silently typed and
=max_attempts_default= is never substituted. This fixes eligibility only; operator-response events and migration
policy are NOT chosen. The mapping of exhaustion onto an unrecoverable terminal and the fresh reconciliation
facts a producer would need are separate open questions not consumed by this module.
